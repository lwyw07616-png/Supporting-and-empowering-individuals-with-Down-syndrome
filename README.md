# خطوة 🌟 | منصة تعليمية لتمكين ذوي متلازمة داون

منصة ويب تفاعلية بالعربية (RTL) في **ملف واحد `index.html`**، بدون مكتبات ولا سيرفر ولا ملفات صوت خارجية. تعمل على الموبايل والكمبيوتر، وتحفظ التقدم على جهاز المستخدم.

## المحتوى
| القسم | الوصف |
|---|---|
| تعلّم | الحروف والكلمات · الأرقام والحساب · الألوان والأشكال · اللغة والتواصل (5 أسئلة لكل نشاط) |
| ألعاب | لعبة الذاكرة (6 أزواج) · ترتيب الأرقام (5 جولات) |
| مهارات الحياة | ارتداء الملابس · غسل اليدين · تنظيف الأسنان · ترتيب الأشياء · السلامة الشخصية |
| مهارات العمل | الكمبيوتر · النقود · التسوق · العمل المكتبي |
| إنجازاتي | 8 أوسمة + نقاط + 5 مستويات (مبتدئ ← بطل) |
| ولي الأمر | اسم الطفل، نسب التقدم، آخر النشاطات، مسح البيانات |
| المعلم | خطة أسبوعية تظهر في الرئيسية، تقرير قابل للنسخ، تجربة الأنشطة، **إعدادات الصوت** |

## الصوت 🔊
الصوت مبني بالكامل داخل الملف من مصدرين:
1. **مؤثرات صوتية** مولّدة بـ Web Audio API (بدون ملفات mp3).
2. **قراءة صوتية بالعربية** بـ Web Speech API (يفضّل صوت `ar-EG` ثم أي صوت عربي متاح).

| الحدث | الصوت |
|---|---|
| ضغط أي زر أو تبويب | نقرة خفيفة |
| ظهور سؤال (حروف/أرقام/ألوان/لغة) | قراءة السؤال. الضغط على السؤال أو الصورة يعيد القراءة |
| إجابة صحيحة / خاطئة | نغمة نجاح + «أحسنت/ممتاز…» ، أو نغمة خطأ + «حاول مرة أخرى» مع الإجابة الصحيحة |
| قلب بطاقة في الذاكرة | صوت قلب + نطق اسم الصورة، ونغمة عند التطابق أو الخطأ |
| ترتيب الأرقام | نطق الرقم عند الاختيار الصحيح، ونغمة خطأ عند الغلط |
| خطوات الدروس | صوت انتقال + قراءة الخطوة، وزر «🔊 استمع» للإعادة |
| شاشة المكافأة | لحن فوز + «أحسنت [الاسم]، حصلت على X نقطة» |
| ترقية مستوى أو وسام جديد | لحن + إعلان صوتي |
| الإنجازات | الضغط على وسام يقرأ اسمه وشرطه |
| حفظ الاسم | ترحيب صوتي |

**التحكم:** من تبويب «المعلم» ← «إعدادات الصوت» (تشغيل/إيقاف المؤثرات، تشغيل/إيقاف القراءة، سرعة الصوت، تجربة الصوت). الإعدادات تُحفظ على الجهاز.

## ملاحظات مهمة
- المتصفحات تمنع الصوت قبل أول لمسة، لذلك يبدأ الصوت بعد أول ضغطة.
- القراءة بالعربية تعتمد على أصوات الجهاز. لو لم يوجد صوت عربي تعمل المؤثرات فقط (تظهر رسالة بذلك في إعدادات الصوت). أفضل نتيجة: Chrome/Edge، ولـ Android يلزم تثبيت صوت Google العربي.
- على iOS قد تتأخر القراءة التلقائية أحيانًا، وزر «🔊 استمع» يعمل دائمًا.
- الخط يُحمَّل من Google Fonts، وبدون إنترنت يُستخدم Tahoma تلقائيًا.

## التخزين
- التقدم: `localStorage` بالمفتاح `khotwa2`
- إعدادات الصوت: `localStorage` بالمفتاح `khotwa_snd`
- لا يُرسل أي شيء لأي سيرفر. زر «مسح البيانات» عند ولي الأمر يحذف التقدم.

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub (مثلًا `khotwa`).
2. ارفع `index.html` و`README.md` (Add file ← Upload files ← Commit changes).
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/khotwa/`

أو بالأوامر:
```bash
git init
git add index.html README.md
git commit -m "خطوة: منصة تعليمية بالصوت"
git branch -M main
git remote add origin https://github.com/USERNAME/khotwa.git
git push -u origin main
```
